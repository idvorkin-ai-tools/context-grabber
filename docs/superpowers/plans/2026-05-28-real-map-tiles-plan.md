# Plan — Real map tiles on the Places tab

Engineering plan for the spec change in [`2026-05-25-tabbed-app-design.md`](../specs/2026-05-25-tabbed-app-design.md) (Places section, ~line 68 + acceptance ~line 246). Tracks `context-grabber-c5p`.

## Why this plan exists

`StylizedMap` was designed library-free (pure View circles on a tinted backdrop). It renders pins in correct relative position but no streets, water, or parks. To a user it reads as "dots on a square," not a map. Swap to real Apple Maps tiles via `react-native-maps`.

## Library choice

`react-native-maps` (v1.x, RN 0.83 / Expo SDK 55 compatible). On iOS it uses `PROVIDER_DEFAULT = Apple Maps` — no API key, no Google account, no usage fees. The codebase has zero existing map deps so no conflict.

## File plan

- `components/StylizedMap.tsx` — rewrite internals; keep `Props` (`currentLocation`, `knownPlaces`, `height`, `path: PathPoint[]`) and the export name. PlacesScreen import stays.
  - Delete: projection math, `useLayoutEffect` frame measurement, segment-rotation polyline code (~250 lines go away).
  - Add: `<MapView provider={PROVIDER_DEFAULT}>` with `initialRegion` from bounding box; `<Marker>` per known place + one for current location; `<Polyline coordinates={pathLatLng}>` when `path.length >= 2`.
  - Region: reuse the existing lat/lng bounding box math; convert min/max → `{latitude, longitude, latitudeDelta, longitudeDelta}` with 20% padding (Apple Maps shows more on screen than the box implies, so smaller padding than the SVG version's 10%).
- `package.json` — `"react-native-maps": "^1.x"` (pin to the latest 1.x compatible with RN 0.83).
- `ios/Podfile.lock` — regenerated by `pod install`.
- `ios/ContextGrabber.xcodeproj/project.pbxproj` — picks up the new pod; do NOT regenerate via `expo prebuild` (per CLAUDE.md — wipes `DEVELOPMENT_TEAM`).

## Build / deploy

Native install. OTA cannot ship this — must rebuild.

```
npm install react-native-maps@^1
cd ios && pod install && cd ..
just deploy
```

## Tests

- Existing `__tests__/` tests don't import `StylizedMap` (it's view-only). No new tests needed for the swap itself.
- Manual verification on device: pins anchor on real geographic positions, polyline traces today's stays, pan/zoom works.

## Rollback

`git revert` of the swap commit + `pod install` rolls back cleanly. No data migration.
